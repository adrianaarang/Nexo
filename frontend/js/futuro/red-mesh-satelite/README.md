# Red mesh / satélite — roadmap futuro

No forma parte del MVP (solo un 14,3% de los votos la marcó como imprescindible,
y el 62,5% del grupo prefiere decidir el diferencial técnico "según el alcance
del MVP", no como bandera del proyecto).

Idea para cuando llegue esta fase: combinar una red mesh entre los móviles de
los usuarios (tipo Bridgefy/goTenna) para corto alcance, con nodos comunitarios
fijos con conexión satelital (tipo Starlink) en puntos clave, para dar salida
a internet real cuando el resto de infraestructura esté caída.

Ver también `infra/mesh-satelite/notas-tecnicas.md` en la raíz del proyecto.
